
# HR Data Analysis Using Python

## 📊 Project Overview

The **HR Data Analysis Using Python** project focuses on analysing employee data to understand workforce distribution, salary patterns, employee performance, work modes, hiring trends, and employee attrition.

Using Python libraries such as Pandas, Matplotlib, and Seaborn, this project explores HR data to identify patterns that can support data-driven human resource management and workforce planning.

## 🎯 Project Objectives

- Analyse employee distribution across departments and job titles.
- Understand employee status, including Active, Resigned, Retired, and Terminated.
- Compare average salaries across departments and job titles.
- Analyse employee experience and performance ratings.
- Compare Remote and On-site work modes.
- Examine employee resignations and terminations by department.
- Identify yearly hiring trends.
- Explore salary differences and attrition patterns across departments.

## 💡 Key Insights & Findings

- **Employee Status:** The dataset contains 734,439 Active employees, 209,342 Resigned employees, 52,462 Retired employees, and 52,332 Terminated employees.
- **Department Distribution:** IT has the largest employee population, with 315,028 records, followed by Sales with 209,524.
- **Work Mode:** There are 628,436 On-site employees and 420,139 Remote employees.
- **Average Salary:** IT has the highest average salary among departments in the provided analysis, followed by Finance.
- **Performance:** The overall average performance rating is approximately 3 out of 5.
- **Attrition:** R&D has the highest department-wise resignation percentage at approximately 20.15%, followed closely by Finance at 20.13%.
- **Remote vs. On-site Salary:** The calculated average salaries are similar for both work modes in the provided analysis.
- **Experience:** Employee experience ranges from 0 to 15 years in the dataset.
